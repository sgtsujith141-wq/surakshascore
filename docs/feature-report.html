01 Executive Summary

SurakshaScore (PSS) is a mobile-first digital security hygiene application designed to evaluate, explain, and improve an individual's personal security posture in 3 to 5 seconds. Unlike conventional antivirus apps that rely on opaque cloud telemetry or alarmist alerts, SurakshaScore operates on a 100% deterministic, zero-cloud baseline where security telemetry is evaluated directly on the device.

The platform audits 5 comprehensive attack surfaces: Device Integrity, Application Permissions, Network Encryption, Credential & Account Safety, and Behavioral Security Habits. Every score deduction is mathematically explainable, backed by verifiable on-device evidence, and accompanied by 1-click OS settings resolution paths.

02 Architecture Overview

Frontend & Core Layer React 18 + TS
Strict TypeScript architecture built with Vite, TailwindCSS (Kinetic Industrialism token extensions), Lucide React iconography, and modular React components.
Native Runtime Bridge Capacitor 6.x
Hardware-level telemetry via @capacitor/device and native plugin bridges for patch staleness, screen lock enclave, and developer bridge options.
Deterministic Scoring Engine Pure Functions
Pure mathematical evaluation without runtime AI drift, floating-point ambiguity, or hidden weights. 100% covered by 21 Vitest test suites (107 unit tests).
Offline Hardware Enclave Zero-Knowledge
Local credentials, vault tokens, and OTP seeds reside exclusively in device hardware storage. Passwords are never synced or transmitted to remote servers.
Key Architectural Invariants (§8 of Spec)

1. Deterministic Math: Identical inputs always yield the exact same score across runs.
2. Critical Finding Cap: Any active critical severity vulnerability strictly prevents a perfect 100 score.
3. Proportional Weight Redistribution: When OS privacy limits probing (e.g. iOS App enumeration), unavailable weights are scaled proportionally across remaining scoreable categories without penalizing the user.

04 Deterministic Scoring Engine

The SurakshaScore calculation is pure, explainable mathematics designed so non-technical users and judges can easily verify how every single point was earned or lost.

// 1. Category Score Formula (§6.1)
CategoryScore = max(0, 100 - Σ(FindingSeverityPenalty × ConfidenceMultiplier))

// 2. Overall Score Formula
OverallScore = min(99 [if critical open], Σ(CategoryScore × NormalizedWeight))
Security Category Standard Weight iOS Scaled Weight (§6.2) Primary Probed Signals
Device Integrity 25% (0.25) 33.3% (0.333) Security patch staleness, screen lock type, developer bridge (ADB), unknown sources, encryption.
App Permissions 25% (0.25) 0% (Excluded) Package inventory, 6 suspicious capability combos (SMS+Internet, Surveillance Triad), dormant apps.
Network Security 15% (0.15) 20.0% (0.200) Open captive Wi-Fi, active VPN encryption proxy, public hotspot safeguards.
Account & Identity 20% (0.20) 26.7% (0.267) Breached identities, leaked credentials, password reuse rate, 2FA authenticator coverage.
Security Habits 15% (0.15) 20.0% (0.200) 20-question weighted self-assessment + scenario-based phishing response evaluation.
Severity Penalties
• Critical: -40 pts (e.g. Screen lock disabled, SMS+Internet combo)
• High: -20 pts (e.g. Stale security patch >90d, Known email breach)
• Medium: -10 pts (e.g. Developer options active, Reused password)
• Low: -5 pts (e.g. Weak PIN length, Dormant app with permissions)
Confidence Multipliers
• VERIFIED (1.00×): Cryptographically or OS verified.
• PERMISSION_BASED (1.00×): Declared runtime permissions.
• SELF_REPORTED (0.60×): Self-reported habit answers receive a 40% discount to prevent user bias from dominating the score.

05 Security, Privacy & Data Storage

SurakshaScore is architected around the core principle that privacy claims must be technically enforceable, not just written in a privacy policy.

Data Asset Storage Location Leaves Device? Encryption & Protection Mechanism
Vault Passwords & Secrets Local Hardware Enclave Never AES-256-GCM derived via PBKDF2/Argon2 hardware enclave key.
Pwned Password Queries Ephemeral Memory 5-Char SHA-1 Prefix Only K-Anonymity range algorithm. Plaintext password and full hash never leave memory.
App Inventory & Permissions Local Device Storage Never Stored in private app sandbox (localStorage cache).
Audit Snapshots & Scores Local Storage & Supabase Mirror Optional Cloud Sync Anonymized UUID scan records with zero PII or device identifiers.
Explicit Privacy Invariants

SurakshaScore NEVER collects, reads, transmits, or logs: Passwords, OTPs, PINs, Bank account numbers, Credit/Debit cards, Contacts, SMS message text, Browsing history, or GPS location coordinates.
